# PetSphere

## Project Overview

PetSphere is a responsive web application for managing pet care.

## Project Structure

    src/
    ├── components/
    ├── pages/
    ├── hooks/
    ├── assets/
    ├── App.tsx
    └── main.tsx

## Technologies & AI Tools

-   React
-   TypeScript
-   Tailwind CSS
-   Vite
-   Claude AI
-   Lovable AI

## Installation

``` bash
npm install
npm run dev
```

## How to Use

1.  Login.
2.  Create a pet profile.
3.  Manage feeding, health, appointments, gallery, and notes.

## Future Improvements

-   AI Pet Assistant
-   Push Notifications
-   Cloud Sync
-   Multi-pet Support
